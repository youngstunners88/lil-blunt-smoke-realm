What are the controls for Lil Blunt: The Smoke Realm?

Move with the Left and Right arrow keys, jump with Spacebar, throw axes with Enter, hold Shift to sprint, and press K for a burst dash.

Full control list

  • Left / Right arrow keys — move
  • Spacebar — jump
  • Enter — throw axes
  • Shift — sprint
  • K — burst dash

The character will not move — what is wrong?

The most common reason is that the game does not have keyboard focus. Click once on the game area after it loads, then use the keys above. WASD is not bound; use the arrow keys to move. For more fixes, see the troubleshooting page.

Does it work on a phone?

The game is built around a keyboard, so it is designed for a desktop or laptop browser. There are no on-screen touch controls in the current build.
